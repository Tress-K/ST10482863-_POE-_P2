TechNova IT Solutions Website - README
Project Overview
TechNova IT Solutions is a professional business website developed to showcase the company’s services, projects, background, and contact information. The website was created using HTML and CSS, with a focus on providing a modern, responsive, and user-friendly experience.
Technologies Used
1.	HTML5 – Used to create the structure and content of the website pages.
2.	CSS3 – Used to improve the design, layout, colours, typography, and responsiveness.
3.	GitHub – Used for project storage, version control, and tracking development progress.
Website Pages
The website consists of five main pages:
1.	Home: Introduces TechNova IT Solutions and provides an overview of the company.
2.	About: Provides information about the company, mission, and values.
3.	Services: Displays the IT services offered by the company.
4.	Portfolio: Showcases completed projects and solutions.
5.	Contact: Provides company contact details and a communication form.
CSS Implementation
An external stylesheet was created and implemented across all web pages to maintain a consistent design. The CSS included default styling, typography improvements, layout organisation, professional blue and white colours, decorative elements, and interactive hover effects.
Responsive Design
Responsive design features were implemented using media queries to ensure the website adapts to different screen sizes. Adjustments were made to the layout, typography, navigation menu, and images to provide a smooth user experience on desktop, tablet, and mobile devices.
GitHub Version Control
The project was uploaded to GitHub to manage files and track development progress. Descriptive commits were used to document important updates, including HTML development, CSS improvements, responsive design implementation, and final website enhancements.
Changelog
The development process included improvements such as creating website pages, applying external CSS styling, improving the visual design, adding responsive features, and refining the overall user experience.

Conclusion
The final TechNova IT Solutions website provides a professional, responsive, and visually appealing online platform. The implementation of HTML, CSS, and GitHub practices resulted in a structured website with consistent branding and improved user experience.
